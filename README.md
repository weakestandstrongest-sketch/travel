# travel — 行きたい場所から旅程を自動で組み立てる

行きたい場所のリスト（滞在時間・営業時間・優先度つき）と宿・日数を渡すと、
日ごとの訪問順と時刻つきの行程を自動で組み立てます。
各移動には **乗換案内（Yahoo!乗換案内）** と **Google マップ** のリンクが付き、
行程は **カレンダー（.ics）** にも書き出せます。

## 使い方

```bash
npm install
npm run plan -- examples/kyoto.json             # Markdown で表示
npm run plan -- examples/kyoto.json --format ics --out trip.ics   # カレンダーに取り込む
npm run plan -- examples/kyoto.json --format json                 # 他のアプリ連携用
npm test
```

出力例（`examples/kyoto.json`、抜粋）:

```
## 1日目 2026-11-21（土）
- 09:20–10:50 伏見稲荷大社
- 11:13–12:43 清水寺
- 13:07–14:07 銀閣寺
- 14:32–15:32 錦市場
宿に 15:51 ごろ帰着
## 2日目 2026-11-22（日）
- 09:23–10:53 二条城
- 11:16–12:16 金閣寺
- 12:47–14:17 嵐山 竹林の小径
宿に 14:57 ごろ帰着
```

## 入力ファイル

```jsonc
{
  "startDate": "2026-11-21",   // 初日
  "days": 2,
  "dayStart": "09:00",         // 宿を出る時刻（既定 09:00）
  "dayEnd": "19:00",           // 宿に戻るリミット（既定 19:00）
  "mode": "transit",           // transit | walk | car
  "base": { "name": "京都駅", "station": "京都", "lat": 34.9858, "lng": 135.7588 },
  "spots": [
    {
      "name": "清水寺",
      "station": "清水五条",    // 任意。乗換案内はこの駅名で検索する
      "lat": 34.9949, "lng": 135.785,  // 省略すると名前から自動で調べる
      "stayMinutes": 90,
      "open": "06:00", "close": "18:00", // 任意
      "priority": "must",       // must | want（既定 want）
      "day": 1                  // 任意。この日に行きたい
    }
  ]
}
```

`lat` / `lng` を省略した場所は OpenStreetMap（Nominatim）で名前から座標を調べます
（1秒に1件ずつ問い合わせるので、件数が多いと少し時間がかかります）。

## しくみ

```
入力(JSON) ─▶ ジオコーディング ─▶ プランナー ─▶ 出力（Markdown / ICS / JSON）
              providers/geocoder   core/planner     export/*
                                      │
                                      ▼
                             所要時間の見積もり
                             providers/estimator
```

プランナー（`src/core/planner.ts`）はヒューリスティックで行程を組みます。

1. 各日について「日付指定 → must → want」の順に場所を入れていく
2. その日の最初の1件は宿から最も遠い場所（同じ方面の場所が同じ日にまとまりやすい）
3. 以降は「宿に戻る時刻が一番早くなる位置」に1件ずつ挿入（営業時間・帰着リミットを守れない挿入は採用しない）
4. 最終日以外は、残りの滞在時間を残り日数で均した量に達したらその日を締める（初日に詰め込みすぎない）
5. 最後に 2-opt で訪問順を改善
6. 入りきらなかった場所は理由つきで「入らなかった場所」に出す

移動時間は今のところ **直線距離からの概算**（`StraightLineEstimator`）です。
近距離は徒歩、それ以上は電車・バス（固定ロス12分 + 時速25km）として計算します。

## 今後の連携について

| 連携先 | 今の状態 | 今後 |
| --- | --- | --- |
| 乗換案内 | 各移動に Yahoo!乗換案内の検索リンク（出発時刻つき）を出力 | 乗換案内 API（駅すぱあと / NAVITIME / ジョルダンなど）で実際の所要時間・運賃を取得 |
| カレンダー | `.ics` で書き出し → Google カレンダー / iPhone カレンダー等に取り込み | カレンダー API に直接登録 |
| 日々のアプリ | `--format json` で行程データを書き出し | 連携先のデータ形式・API に合わせたエクスポーターを `src/export/` に追加 |

乗換案内 API をつなぐときの差し込み口は `TravelTimeEstimator`（`src/providers/estimator.ts`）です。
プランナーは組み合わせを大量に試すため、全地点間の所要時間を先にまとめて取得・キャッシュし、
その値を返す実装に差し替える想定です（API 呼び出しは地点数² 回で済みます）。

## まだやっていないこと

- 昼食などの休憩枠
- 日ごとに宿が変わる旅程（周遊）
- 曜日ごとの定休日・季節で変わる営業時間
- 実際の時刻表に基づく移動時間
- 画面（Web / スマホアプリ）
